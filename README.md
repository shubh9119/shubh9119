**Production-Grade AI Receptionist built from First Principles (Zero Framework Bloat)**

[![Pytest](https://img.shields.io/badge/Tests-56%20Passed%20(0.39s)-brightgreen?logo=pytest&logoColor=white)](https://github.com/shubh9119/restaurant-agent)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](https://github.com/shubh9119/restaurant-agent/blob/main/LICENSE)

</div>

```text
An autonomous AI receptionist capable of conversational table bookings, real-time availability checks,
dietary filtering, food pre-ordering, and personalized recommendations using durable customer memory.
```

- 🔄 **Autonomous ReAct Loop**: Multi-turn reasoning engine that safely chains availability checks, table bookings, and food orders in sequence.
- 🛠️ **16 Specialized Tools**: Python reflection decorator (`@tool`) that dynamically generates schemas from type hints with defensive fault recovery.
- 🧠 **Durable Memory Engine**: Persists customer preferences (seating, allergies, favorites) and past order history into the backend database.
- 🧪 **100% Deterministic Testing**: 56 unit tests utilizing `StubLLM` and `MockAPI` fixtures running in `<0.4s` with zero real LLM costs.
